# 美术方向与构图

## 1. 默认气质：铅印 / LETTERPRESS

没有指定风格时，把片子做成一本**会动的印刷品**：纸色底、墨黑字、强调色标记、裁切线与细网格；动效像纸张被推入、覆盖、揭开，而不是 UI 弹窗。目标是“可信、克制、有编辑判断”。

工程另有 4 个成品主题（`swiss` / `cinema` / `quiet` / `tech`），只换令牌不换版式。**选主题与加主题看 `styles.md`**；本文件讲的是所有主题共用的构图、字号、插画与品质线，示例数值以默认主题为准。

## 2. 字号层级

| 角色 | 字号（1080p 基准） | 令牌 |
|---|---|---|
| H1 | 148px / 128px（长标题自动缩号） | `--h1-size` |
| 场景主标题 H2 | 92px | `--h2-size` |
| 字幕 | 58px（`cinema` 46 / `quiet` 44 / `tech` 46） | `--sub-size` |
| Slogan | 42px / 38px，字距 0.08em | 场景内定义 |
| 副题 | 31px | `--body-size` |
| 正文 | 20–24px | — |
| 微标签 | 11–13px，全大写 + 字距 0.2–0.34em | `--font-mono` |
| 数字 | 48–120px | — |

比例原则：主标题与副题至少 2.5×；副题与微标签至少 2×；全片不超过 6 个字号档位。

中文标点做光学收紧：`，。、；：！？` 右侧、`「『（《` 左侧给 -0.36em 边距，逐字 reveal 时才不会出现断口。

## 3. 网格与版式

基准 1920×1080：

- 页眉：左右 96px，top 54px，底线 1px。
- 内容左边距：120px；右侧视觉区通常从 760–900px 开始。
- 页脚/免责声明：右 96px、底 40px，11px mono。
- 裁切标记：四角 96px 内缩，1px 线，长约 26px（`swiss`/`quiet` 可淡化或关闭）。
- 细线分割：1px `var(--hair)`，用于列表行、规格表；不要用卡片阴影堆叠。
- 安全区：内容不要进入 y > 860（字幕带从 880 开始）；`cinema` 有 54px 黑边，上下各多让 54px。

常用构图：

1. **左文右图**（S1–S5）：左侧 120px 起标题组，右侧是插画、编辑器、曲线或素材墙。
2. **居中片名**（S0/S6）：片名居中，强调块在上，slogan 在下，四角裁切标记。
3. **深色面板**（S2/S5）：一块 `--dark` 面板压在主色上，模拟铅版/暗房；面板要有偏移阴影与细边。
4. **卡片网格**（S1/S5/S6）：等宽卡片 + 编号 + 英文微标签；卡片轻微旋转/错位，保留手工感。
5. **数据/规格**（S3/S4）：大数字 + 细线表格 + 参数标签。
6. **全宽仪表**（`tech` 常用）：细网格 + 状态行 + 一个青色焦点，把“系统感”做满。

## 4. 动效语言

- **纸色闪断**：场景之间是硬切，不做溶解。切点前后 ±0.10s 叠一层纸色闪白（峰值 0.93）；字幕在闪白之上保持连续。
- **连续运镜**：每个场景容器有 0.6%→1.6% 的轻微推近 + ±8px 漂移，奇偶场景方向相反；场景内部不要再做整场缩放或淡入淡出。
- **遮罩揭示**：标题从下方 100% 高度上推，像印刷滚筒压过；不要淡入淡出大字。
- **纸层推移**：卡片/面板以 8–24px 位移进入，带 1–2% 缩放，模拟纸张叠放。
- **强调色先到**：强调块/线常比文字早 0.1–0.2s 出现，作为视觉锚点。
- **数字滚动**：计数器用 `E.outCubic`，2–3 秒完成；不要弹性回弹。
- **65% 收住**：主动效在场景时长的 65% 前完成，最后 35% 留给阅读。
- **禁止**：玻璃拟态、霓虹渐变、发光、3D 翻转、弹簧抖动、大面积模糊。

节奏：每 2–4 秒一个信息动作；一个场景最多两个主动效（标题揭示 + 内容入场），其余保持静止。

## 5. 插画语言

`kit.frame(variant)` 内置 8 个 SVG 场景（巷口、早餐摊、窗格、公交站、雨、树影、车流、空镜），统一为双色 + 一个暖点，全部跟随主题：

- 背景用 `var(--ill-paper)`；
- 主体用 `var(--ill-ink)` 的剪影/线稿；
- 局部用 `var(--warm)` 点一个小信号（车灯、门牌、太阳）；
- 唯一强调元素可用 `var(--accent)`，每帧不超过一个。

新增画面时：

1. 在 `scene-kit.js` 的 `SCENES` 对象里加一个 `viewBox="0 0 280 186"` 的 SVG 字符串。
2. 只用 `var(--ill-paper)` / `var(--ill-ink)` / `var(--warm)` / `var(--accent)` 四个变量；不要写十六进制。
3. 主体轮廓优先，细节不超过 3 层；缩到 300px 宽仍要能辨认。
4. 不要写实照片、不要复杂渐变；不要依赖某个主题的亮度（深色主题会整体反相）。

## 6. 强调色怎么用

- 每帧最多一个强调色焦点：一个方块、一条进度、一个数字、一个印章。
- 面积不超过画面 3–5%；深色主题下可到 6%（信号线本身很细）。
- 用于：场景编号、切点标记、进度、关键数字、印章、字幕前的标记。
- 同一画面出现两个强调元素时，必须是一组（如编号 + 对应标记），否则删一个。
- 强调色变量是 `--accent` / `--accent-2`；旧代码里的 `--red` 是别名，新代码用 `--accent`。

## 7. 字幕与页脚

- 字幕样式全部由主题令牌控制：`--sub-font/size/weight/color/track/marker/align`。
- `letterpress`：左对齐 + 方块标记 + 上方时间码（24fps 基准）。
- `swiss`：左对齐粗体，无标记；`quiet`：圆点标记、无时间码；`cinema`：居中、金色细线、无时间码；`tech`：`▸` 标记、等宽时间码。
- 页眉右侧是场景编号与英文类目：`03 — 字幕 · CAPTION`。
- 页脚左边版权，右边 `END OF REEL · 60 SEC` 或技术参数。
- 时间码用 `config.tcFps`（默认 24），全片一致；改主题不要改时间码语义。

## 8. 微调与换主题

- 换整体风格：改 `config.style` 或建工程时 `--style`；细节见 `styles.md`。
- 只换品牌色：在主题文件里覆盖 `--accent` / `--accent-2`，再确认强调色对纸对比 ≥ 3:1。
- 只换字体：覆盖 `--font-display` 与 `--title-weight`；中文宋体/黑体二选一，不要混三种。
- 换完必须重跑 `npm run check`、`npm run qa`（版式/节奏/抽帧全套），并出一次 `npm run styles` 对比。
- 不要在场景文件里为某个主题写特例；主题只改表现令牌与少量 `html[data-style]` 覆盖。

## 9. 画幅适配

模板的场景坐标是按 16:9（1920×1080）排的。改成 9:16 时**不能只改 config 宽高**，否则右侧视觉区会被裁掉。按场景重排：

| 场景 | 16:9 | 9:16 建议 |
|---|---|---|
| S0/S6 | 居中片名 | 居中，字缩小 55–65%，安全区上下各留 12% |
| S1 | 左文右 8 卡 | 上文下卡：标题占上 40%，卡片两列纵排 |
| S2 | 左文右编辑器 | 编辑器全宽置下，标题压在上方，隐藏右侧检查器 |
| S3 | 上标题下字幕轨 | 上下堆叠，波形缩短，字幕行减到 3 条 |
| S4 | 左预览右曲线 | 曲线全宽，预览缩到上方 1/3 |
| S5 | 标题 + 8 卡 + 右侧统计 | 卡片两列，统计改为底部横排 |

改完必须重新跑 `npm run qa`；竖屏下字幕字号建议 64–72px，底部安全区 ≥ 140px。

## 10. 质量线

过稿前问自己：

- 截一帧发到手机上看，标题 2 秒内能读完吗？
- 遮住动效，只看静态版式，像一张能发出去的版面吗？
- 强调色是不是只在一个地方？
- 页眉/页脚/裁切线在切点前后是否稳定？
- 切点闪白后是否干净接上新一镜，没有双曝光或长时间空帧？
- 有没有任何一帧出现半截文字、出框卡片、压住字幕、未落值的数字？
- 换主题后，插画/深面板/字幕是否仍然清楚？

只要有一项否，回到 `seek` 或布局修正，不要靠加动效掩盖。更多品味规则见 `design-taste.md`。
