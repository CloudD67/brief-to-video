# 扩写手册 · 一句话 → 一个可拍的世界（宣传片 promo）

> 一支片之所以像“功能演示”，几乎总是因为从 brief 直接跳到了分镜。
> 扩写不是写作文，是先把“可拍的画面”做够，再删到片长。
> 生产级要求：一句话 brief 先扩写成 `treatment.md`，写到每个空间、每个序列、每个候选镜都能直接拍；用户确认后才写分镜、才建工程。
> **本文只适用于宣传片（promo）。** MV 的稿子要厚得多：背景、人物、关系、母题、歌词段、镜头候选都写，见 `mv-craft.md` §0 与 SKILL 的 M1。把宣传片的四层扩写搬进 MV，会得到一支没有人物、没有前因后果的歌词幻灯片；把 MV 的人物小传搬进宣传片，会得到一份没人拍得起的设定集。
> **不设字数上下限**：写得越详细越好，但每一句都要能变成画面、动作或镜头；不要用形容词和空话凑长度。

---

## 0. 写作原则

1. **先扩写，后分镜**：跳过扩写直接写 5–8 拍，结果一定是“一屏一个卖点”。
2. **主体锚点**：每个序列里，主体（产品或它的直接效果）必须可见。判断方法很笨但有效——把主体换成一朵花，如果 treatment 还成立，那这支片已经跑题了。
3. **写可拍的名词和动词**：地点、时间、光、材质、动作、颜色；少用形容词（“强大 / 优雅 / 无缝”）。能用名词和动词说清，就不用形容词。
4. **先多后少**：60s 片候选镜头 ≥30，成片留 20–30；先做够再删，不要一开始只写 7 个。
5. **不设字数，写到能拍**：写得越详细越好；判断标准不是字数，而是每个空间、动作、镜头都能直接落到画面。删掉一句不损失信息，说明这句是空的。
6. **颜色是结构**：先写色彩脚本再画第一帧；全片一个颜色 = 没有色彩脚本。

**创意空间**：配额（空间 / 序列 / 镜头 / 色域）是下限，不是处方。在锚点之内，鼓励发明非显然的画面与结构——一个意想不到的转场、一个只有这支片才成立的细节、一个不落俗套的收束。每支片至少留 **一个 wild card 镜头**：它不必直接展示主体，但必须解释主体带来的改变。示例里的清晨、地铁、咖啡杯只是示范，不是必选素材；空间、镜头、颜色必须从这一支 brief 长出来，不要为了凑表复制示例。

## 1. 四层扩写（宣传片的厚度）

| 层 | 要回答的问题 | 产物 |
|---|---|---|
| **世界层** | 在哪、什么时候、什么天气、什么光、什么材质、什么声音 | 3–6 个具体空间，每个都有时间与光源 |
| **人物层** | 谁在用、手上在做什么、留下什么痕迹 | 一个具体的人（或一只手的视角）；**只写与产品动作有关的部分，不写前史、关系与内心戏**——那些属于 MV |
| **产品层** | 怎么出场、有哪些细节、发生了什么变化、被谁看见 | 产品的 3 个物理动作 + 3 个材质细节 |
| **情绪/色彩层** | 开头/转折/落点的情绪词是什么；每个情绪配什么色与光 | 4–6 组色板，标出用在哪几场 |

写完检查：每层是否都有 5 个以上**只能属于这支片**的名词。没有就继续扩。

宣传片不需要世界观设定、人物小传、关系线、母题变奏；这些是 MV 的扩写任务。宣传片的“人”是动作的载体，不是故事的主角。

---

## 2. 配额（硬下限，按片长缩）

表里全是**下限，不是上限**：空间、序列、候选镜都可以更多，最后再删；不设字数，也不设数量上限。写得越详细越好。

| 维度 | 60s | 30s | 15s | 怎么验 |
|---|---|---|---|---|
| 可拍序列 | ≥10（删到 6–8） | ≥8（删到 5–6） | ≥6（删到 4–5） | 序列表行数 |
| 不同空间 | 6 | 5 | 4 | 序列表 `地点` 列去重 |
| 候选镜头 | 30 | 20 | 14 | 镜头候选表行数 |
| 成片镜头 | 20–30 | 14–20 | 10–14 | 分镜表；7 个镜头的 60s 片先怀疑自己 |
| 色域 | 4（每个 ≥8% 时长） | 4 | 3 | 色彩脚本 + `npm run qa:variety` |
| 主色域占比 | ≤60% | ≤60% | ≤60% | `qa:variety` 报告 |
| 明暗跨度 p90−p10 | ≥0.10 | ≥0.10 | ≥0.10 | `qa:variety` 报告 |
| 材质/微距镜头 | ≥3 | ≥2 | ≥2 | 分镜表景别列 |
| 人的痕迹 | ≥2（手 / 背影 / 剪影 / 呼气 / 杯子） | ≥2 | ≥1 | 分镜表 |
| 屏幕/UI 镜头（硬件片） | 经验值 ≤30%（仅提示） | 同左 | 同左 | 分镜表类型列 |
| 相邻三镜 | 不得同空间 + 同光 + 同景别 | 同左 | 同左 | 分镜表逐行看 |
| 静止帧占比 | <25%，最长静止段 <1.2s | 同左 | 同左 | `npm run qa:motion` |

## 3. 七步扩写

1. **列 20 个名词**：只写能被镜头拍到的东西。
   > 窗台上的水汽、地铁玻璃的反光、键盘背光在暗处亮起、咖啡杯在纸边留下的圆环、合盖时磁吸的那一声。
2. **写 10 个一句话场景句**：一句一个画面，主语是地点或人，不是产品；写到能直接拍。
3. **做 8–12 张序列卡**：地点 / 时间 / 光 / 动作 / 情绪 / 一句文案（没有文案就留空）。
4. **写 30 镜候选表**：镜号 / 景别（远中近微）/ 机位 / 光 / 材质 / 颜色 / 动作 / 时长。
5. **定 4–6 组色板**：每组给 token 名、主色、光的方向与软硬、出现在哪几场；写清从哪组走到哪组。
6. **删到 20–30 镜**：按 60s 贪心选镜——每个镜头必须提供“新信息”或“新画面”，二者必居其一；同空间同景别的第二镜只留最好的一镜。
7. **过三测试**：换名测试（换掉品牌仍成立）、静音测试（关掉音乐字幕故事仍成立）、灰度测试（去掉颜色后明暗层次仍成立）。

## 5. 从扩写到分镜的压缩规则

- 六段必须齐：**世界 → 仪式（开合/点亮/拿起）→ 细节 → 使用 → 结果 → 收束**。缺世界，片子就退化成演示。
- 60s 内至少 **4 个空间、3 个景别层级**（远/中/近，微距另算）。
- 每个序列只留一个“最贵的画面”，其余镜头为它服务。
- 屏幕是节拍不是舞台：硬件片屏幕镜头经验上不超过三成（只做提示、不设硬配额），且每次出现必须带来新状态（亮起 / 合盖 / 一条消息）。
- 文案只保留 3–4 条字幕 + 标题 + 尾句；扩写里的句子大部分应变成画面，不是字幕。
- 主体必须在关键节点在场：开场、转折、结果。中段可以离开，但不能连续两个序列不回来。

---

## 6. 质量门槛（不过不建工程）

- 细节达标：每个空间、序列、候选镜都写到能直接拍；只有形容词、没有可拍名词的段落要重写。
- 序列 ≥8、空间 ≥6、候选镜 ≥30、色域 ≥4（成片口径 ≥3 个色域、主色域 ≤60%）。
- 至少 2 个“主体不出现也成立、但解释了主体带来的改变”的世界镜头——它们决定片子像不像宣传片，而不是产品目录。
- 换名测试通过：把产品名换掉，treatment 仍然成立且只属于这支片。
- **锚点测试通过**：把主体换成一朵花，treatment 应该立刻不成立；如果仍然成立，说明主体只是贴上去的，回炉重写。
- **跑题自检**：在 treatment 末尾写三行“这支片最可能跑向哪里、我如何拦住它”。写不出，说明方向锁还是空的。
- **用户确认 treatment 之后**才写分镜表；分镜表确认后才建工程。

## 7. 反模式

| 反模式 | 症状 | 改成 |
|---|---|---|
| 从 brief 直接跳分镜 | 7 个镜头、一屏一个功能 | 先写 treatment，凑够 30 镜候选再删 |
| 形容词扩写 | “强大、优雅、无缝协同”写了一大段 | 换成 20 个可拍名词 + 10 个场景句 |
| 一个场景塞多个卖点 | 屏幕里同时演示三个功能 | 一个序列一个动作，功能在动作里被迫展示 |
| 全片只有屏幕 | 观众只看到 UI 在动 | 世界镜头占大部分（硬件片），屏幕只做节拍 |
| 一套色到底 | 全片深青/全片米白 | 4–6 组色板，随情绪推进 |
| 字幕解释世界 | “在安静的清晨……” | 把清晨拍出来：光、水汽、声音 |
| 扩写=抄参考片 | 画面换了名字还是同一支片 | 只借结构，空间/材质/颜色全部重写 |
| **跑题成隐喻片** | 做电脑宣传片，成片是一朵花、一片海、一次抽象旅行 | 每场加“主体在场”检查；wild card 只能有一个，且必须解释主体 |
| **过度设定** | 给 60s 宣传片写人物前史、世界观、关系线 | 删到“谁 + 手上做什么 + 留下什么痕迹”，其余交给画面 |

**病例（2026-11 MacBook 片）**：青色占 82%、全片只有 2 个色域、43% 静止帧、90% 镜头是屏幕。
病因不是转场，是跳过了扩写：一句话 brief 直接写了 7 个屏幕场景。
修法是流程性的——先扩写到 6 个空间、5 组色板、30 镜候选，再删成 60s。

## 8. 示例：一句话 → 扩写摘要

brief：「给 MacBook 做一支宣传片。」

扩写后（摘要，实际 treatment 要写到每个空间与镜头都能直接拍）：

- **方向锁**：主体锚点 = 这台电脑陪一个人把毕业设计做完；这不是功能演示，也不是城市空镜集；wild card = 合盖后屏幕光在墙上留了一秒余晖。
- **世界**：凌晨的自习室（冷白台灯）→ 清晨厨房窗边（暖阳光斑）→ 雨天咖啡馆（玻璃反光）→ 傍晚地铁（移动的窗影）→ 深夜书桌（只亮屏幕）。
- **主角**：一个赶毕业设计的学生；痕迹：便利贴、杯子圆环、合盖时按下的一口气（只写这些，不写前史）。
- **产品动作**：掀盖亮屏 / 合盖带走 / 在膝上打开。
- **色彩脚本**：冷青（夜）→ 暖橙（晨）→ 灰绿（雨）→ 金棕（黄昏）→ 深蓝（夜）→ 中性银（收束）。
- **候选镜 30**：水汽里的窗、手指掀盖、键盘背光亮起、屏幕光打在脸上（只见轮廓）、合盖的磁吸、背包里的边角、地铁玻璃上的反光、杯子在纸上的圆环、夜里风扇的微尘……
- **屏幕镜头 6/30**（20%）：亮屏、壁纸、一条完成提示、合盖前的一秒、锁屏、光标。
- **删到 24 镜**：保留 6 个世界镜、4 个微距、3 个人物痕迹、1 个屏幕节拍组、1 个收束。

这才是“宣传片”；上一支片演示的是“一个功能”。
