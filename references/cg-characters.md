# CG 角色与表演（cg_char.py）

> 适用：story / CG 镜头里的**人**——程序化建模、绑定、面部、口型与表演。角色也是代码：`cg/cg_char.py` 用椭球/放样搭人，手写蒙皮绑到 19 根骨骼，面部用 shape key + 表情部件，逐帧驱动。
> 配套：环境、`film.py` 骨架、`cg_kit` 构件、性能见 `cg-pipeline.md`；本文只讲角色。示范片：`assets/genres/story/cg/character.py`（面摊 6s，说「面好了，趁热吃」）。

## 1. 快速上手

```python
import cg_char as C

fig = C.build('Ya', loc=(0.02, 0.55, 0), height=1.70, yaw=0.18,
              top=(.034, .038, .048, 1),        # 藏青毛衣
              apron=(.060, .034, .021, 1),      # 皮围裙
              hat=(.015, .016, .019, 1))        # 炭黑毛线帽
C.idle(fig, FRAMES, fps=FPS, breath=1.0, sway=0.9, lean=2.2)
C.pose_arms(fig, shoulder=-6, elbow=-22)
C.look(fig, [(1, 0, 15, 2), (52, 6, 2, -1), (FRAMES, 4, 5, 0)])
C.blink(fig, [0.9, 2.4, 4.9], fps=FPS)
C.speak(fig, curve, start_frame=1, gain=0.85)  # curve = cg_audio.envelope(wav, fps=FPS)

K.camera(..., focus=fig['focus'], ...)         # 焦点空物体绑在头上，跟头走
```

`build()` 返回 rig 字典：`arm / head / face / jaw / lids / mouth / lower_lip / tongue / focus / height` 及动画基准值（`*_base`）。所有 perform 函数都往这个字典上写 keyframe。

## 2. 身体比例（单位 = H）

- 全部尺寸按 `height` 归一：`0.92H` 是头中心，`0.50H` 是髋，`1.0H` 到头顶。换身高只改一个数。
- 躯干是 10 圈放样：腰 `0.585H` 收窄（r .082/.053H），肩 `0.795H` 放宽（.110/.066H），颈根 `0.838H`。**肩宽靠躯干放样做、不靠球形三角肌**——球形关节会像人体模型。
- 脖子是锥体 `.790→.900H`，r `.0285→.0265H`，外加领口三圈放样盖住接缝。**脖子短而粗**是「像人」的第一要素，细长脖子立刻出戏。
- 手臂：上臂锥 `.033→.0255H`、前臂锥 `.0255→.0205H`、袖口短锥、肘部椭球补缝、手椭球 `(.019,.037,.0145)H` + 拇指。**上臂起点埋进躯干**（x `.072H`、z `.792H`），锥体端盖被躯干包住，交界线读成袖窿缝；加球形三角肌会立刻变人体模型。手腕在 `.600H`、指尖 `.592H`，肘微屈。
- 默认姿态：双臂垂前（`pose_arms(shoulder=-8, elbow=-34)` 是站立自然位），肘为正 X 旋转会向后翻——**下向骨骼的正 X 是向后弯**。

## 3. 绑定（19 骨 + 手写蒙皮）

- 骨架：`hips → spine → chest → neck → head`，两侧 `shoulder → upper_arm → forearm → hand`、`thigh → shin → foot`。躯干骨垂直向上，**骨轴 = 局部 Y**：head 的局部 Y 是左右转头（扭），局部 X 是点头，局部 Z 是歪头。`look()` 的 `(yaw, nod, tilt)` 就按这个顺序写。
- `_bind(obj, arm, bones)`：逐顶点算到 2 根骨线段距离，按 `d^-3.2` 归一加权，加 Armature 修改器。躯干放样绑 `['hips','spine','chest']`，手臂件绑 `['shoulder.X','upper_arm.X','forearm.X','hand.X']`，腿件绑 `['thigh','shin','foot']`。
- 头部网格用 `_bone_parent(obj, arm, 'head')`：`parent_bone` 的锚点是「骨矩阵 × 沿轴平移骨长」，`matrix_parent_inverse` 必须用这个锚点求逆，否则头会漂。
- 面部小件（眼球、眼皮、眉、嘴、舌、下巴）挂到 head 网格：`_child(obj, head)`（父逆 = 父世界矩阵逆）。**两者都是先 `view_layer.update()` 再取矩阵**；不要链两层（hat 的帽体和帽檐都直接挂 head，不互挂）。
- 手写蒙皮够用，不做自动权重。改比例后要看肘/肩/髋在动效里是否塌陷，塌了加骨或调 `power`。

## 4. 脸与口型

- 下巴是 shape key `jawOpen`：绕 X 轴 17° 的旋转变形，权重 0–1 直接当嘴张度用。
- 嘴部件四层：`cavity`（口腔暗盒，尺度 z 随张口涨）、`lower`（下唇）、上唇不动、`tongue`（舌椭球，张口时下沉后缩）。`speak()` 对四者同时打 key：`jaw.value = vv`，cavity 拉到 `base + vv*(1.25-base)` 并下沉 `.0032H*vv`，下唇下移 `.0060H*vv`，舌下移 `.0050H*vv`。
- 幅度不够会「嘴不动」：**峰值帧要目检**（本例 1.88 / 2.25 / 2.88 / 3.0s）；静音间隙 envelope 归零是正常的，抽帧恰好抽在字间会误判。
- 眨眼：眼皮是绕眼眶横轴的半壳旋转，开 −8°、闭 92°，`blink(fig, times, close=3)` 每闪 3 帧。频率 3–5s 一次，不要机械等距。
- 眼：`eye_r=.0117H`，比早期版本大 45%——小眼在 1080p 近景里就是"豆豆眼"。眼白是压扁椭球 `(.94,.55,.66)×eye_r`；虹膜/瞳孔是**球冠**（`_cap` 切面 −.70 / −.905），正面看虹膜占满眼眶、不露白边——白边是"玩偶眼"的第一来源。高光小球自发光 2.0。眼球中心 `(±.0226H, −.0448H, .0034H)` 要顶到脸皮，凹进去就是空眼眶。
- 眼皮与睫毛：上眼皮是缩放球壳绕横轴转，`lid_open=−6 / lid_shut=92`；下眼皮是同一球壳翻转 182° 压进眼下缘——**上下都有压边，眼白才不和脸皮"接缝"**。睫毛是 `_tube` 五点上弧（横跨 `.0120→.0330H`），贴上眼皮沿遮住眼球与脸的交界。
- 眉：`_tube` 五点弧，压在眼上方 `.0126–.0145H`（比早期低 3–4mm）、外端略降。眉离眼太远、太厚、上挑，立刻显假。
- 鼻：球头 `(.0072,.0038,.0038)H` + 两翼小球，**不做鼻孔**——两个小黑椭球在 1080p 下读成鼻尖上的痣/贴片；做不准的特征宁可删。
- 嘴：口腔是压扁椭球（z 缩到 .10）藏在唇后；上唇五段放样（中段最厚 = 唇峰），下唇独立椭球；`speak()` 只动腔体/下唇/舌。
- 下颌：下巴 shape key 对 `nz<−.10` 的顶点做 X×.145、Z×.075、Y×.030 收窄——**只收 X 会变窄长马脸**，Z 要同步压短。
- 拼接感的根源是**部件边界**：所有部件要么互相嵌入，要么被同材质件盖住缝（低领盖躯干顶盖、短发盖发际线、下眼皮盖眼睑缝）。看不到接缝，就看不到"拼"。
- 配色：肤色 `(.44,.235,.165)` 线性、唇 `(.26,.09,.075)`、虹膜 `(.095,.042,.016)`；肤色 rough .42 + subsurface .12 + 噪声凹凸，避免塑料感。

## 5. 造型参数

- `build(..., skin, hair, top, pants, lips, apron, hat)`：
  - `hat=None` → 头发壳（球体切开、solidify）；`hat=(r,g,b,1)` → 毛线帽（切开球 + 帽檐放样），把发际线整个盖住——**程序化发型最容易假，帽子是最便宜的真实感**。
  - 戴帽时必须**也给短发**：`hat` 分支里再建 `_hair(..., short=True)`（侧面 `|y|<.30` 且 `z<−.16`、后脑 `y<.30` 且 `z<−.42` 处裁掉）。只戴帽不建发，侧脸/低头时帽檐下是一片光头，这是最显眼的拼接。
  - `apron` 分两段弧形片（`_arc_panel`，solidify）：腰片 198°–342° 到 `.625H`；胸片是 234°–306° 的梯形弧（下窄上宽，顶到 `.768H`）——只做腰片会读成「裙子」，胸片才像围裙。都绑 `hips/spine/chest`。
  - 颈带是围裙成立的前提，也是最容易做砸的件：两根 `_tube` 从胸片上角沿**躯干椭圆表面**走（按 `_torso` 环表插值 `surf_y(z, x)`，外偏 3.2mm），末端收进领口半径内。手写几个点会一会儿埋进胸口、一会儿悬空成两根 "铁棍"——这是最刺眼的拼接。胸片顶边不加卷边管（`_tube` 细管会变成一圈塑料亮边），solidify 的厚度就够。
  - 领口四圈放样 `.790→.850H`（毛衣宽领）必须盖住躯干放样的顶盖：顶盖朝上、被灯直照，不盖会变成一条发白的破领子。顶环收到 r `.0335/.0315H` 也一样要盖。
- 材质用 `_mat(..., bump=(scale,detail,strength,distance[,rough_range]))`：毛衣 rough .78 + 细噪声、围裙 rough .62 + 较粗噪声、帽子 rough .9 + 强噪声。

## 6. 对白管线（say → wav → 包络 → 口型）

```bash
say -v Meijia -o assets/cg-line.wav --data-format=LEI16@22050 \
    '[[slnc 1900]]面好了，趁热吃。'
```

```python
curve = A.envelope(wav, fps=FPS, start=0, end=DURATION, gate=0.06, knee=0.5)
C.speak(fig, curve, start_frame=1, gain=0.85)
```

- 前导静音写进 `say` 文本（`[[slnc 1900]]`），让口型从对白起点才开始；envelope 的 `gate` 把底噪归零。
- 曲线是**能量包络不是音素**：中文短句够读；要闭唇音 m/b/p 的精确闭合属于后续版本。
- `say` 可能挂起：生成函数要有超时、已有文件 >4KB 直接复用（见 `character.py: make_line`）。
- **纯旁白成片会被截短**：一句话 wav 常只有 3–4s，`encode.js` 的旁白分支必须 `apad` 补静音，否则 `-shortest` 把 6s 成片截成 3.7s（已修，见 `encode.js` 的 `apad[a]`）。
- 无音轨时用 `A.procedural(frames, syllables_per_sec=3.2)` 预演，确定性、可复现。

## 7. 表演与镜头

- `idle()`：呼吸 0.22Hz（胸腔 ±0.9°、髋 ±1.5mm）+ 重心 0.06Hz 慢摆 + 可选前倾 `lean`。**每支片都要 idle**，静止的角色会立刻暴露是模型。
- `look()` keys 是 `(frame, yaw, nod, tilt)`：先定「看不看镜头/客人」，再给 2–3 个过渡；头部转身要 8–12 帧，瞬移会像跳帧。
- 说话时 `speak()` 自带 0.8° 颈部点头（`nod=1.0`）；别再加头部 bob，会过。
- 机位：角色 3/4 侧 45°、48–65mm、f/2.0、焦点挂 `fig['focus']`。**前景留道具**（碗/蒸汽/桌沿）压住画面下缘，人物才「在场景里」而不是立在空地上。
- 布光按「皮肤可读」做：暖主光在脸前 45°、冷轮廓在脑后、霓虹色补光，主光别超过 20W（实测 38W 会把深色围裙打成米色）。

## 8. 迭代工作流（不要一上来全渲）

```bash
node tools/cg-render.js --file cg/character.py --at 0.2,1.8,2.25,4.6 --samples 8
```

- 1080p / 8 采样约 3.5s/帧，24 采样约 7s/帧（角色+体积蒸汽+雨，M4）。先 8 采样定构图、脸、光，再全渲——144 帧约 17 分钟。
- 抽帧点覆盖：首帧（穿模）、说话峰值（嘴）、眨眼前后、末帧（封面候选）。
- 改完脸/头饰立即抽一帧近景；**头部相关改动最容易把帽子、眉毛、发际线改飞**。

## 9. 验收清单

- [ ] 近景看「像不像人」：脖子、肩线、下巴、眉毛方向、眼睛有没有高光。
- [ ] 说话峰值帧嘴张开、口腔可见、舌在下唇后；静音帧闭合。
- [ ] 眨眼不被帽子/眉毛遮挡；转头时颈-肩无裂缝。
- [ ] `focus` 跟头走，景深不会在说话时把脸虚掉。
- [ ] 首帧无穿模（手肘穿台面、围裙穿腿）。
- [ ] 全片渲完后 `ffprobe` 帧数 = `DURATION×fps`，再 encode。

## 10. v2：融合网格 + 贴花五官（《留一碗》，静默片）

v1 的「拼接感」来自独立件之间的缝：眼球/眼睑/睫毛浮在脸上，袖子和肩垫互插，头发和帽子是两层壳。v2 换做法（实现见《留一碗》工程 `cg-liuyiwan/cg/cg_char.py`，本模板仍默认 v1，因为它要保留口型）：

- **身体整块焊**：毛衣+袖子+领口 join 后体素重构（voxel `0.0016H`、smooth 3），肩、肘、领口焊成一片曲面，只剩服装结构线；手=掌+指+拇指焊成连指手套状；帽子/兜帽也是实心织物。头=颅骨+耳+鼻+颈桩焊成一整块皮肤，头颈缝藏进高领/围巾。
- **五官是画上去的**：`_project_decal()` 沿 +Y 射线把 XZ 轮廓投到面部，再 solidify 加薄壳。没有眼白、没有悬浮眼皮、没有嘴唇管——所以没有「贴片浮在脸上」的可能。层高阶梯：唇 `0.00018H` → 眼睑褶 `0.00042H` → 眉 `0.00050H` → 眼 `0.00055H` → 虹膜 `0.00090H` → 瞳孔 `0.00120H` → 高光 `0.00155H`；顺序不能乱，否则瞳孔被虹膜盖住。
- **眨眼不用骨骼**：眼睛族挂在一个空物体下，`blink()` 把眼组 z 缩到 ~0.06 再弹回，3 帧一眨；眼睑褶留在皮肤上不跟着缩，才像眼皮压下来。
- **高光要小、要暗**：半径 `0.00034H` 的圆片，自发光 **0.3**——到 0.6 以上在 1080p 里就是「机器人的发光眼」；两只眼的高光都放在瞳孔内上角（镜像），一只在瞳内一只在瞳外会读成斜视。
- **皮肤不是塑料**：subsurface 0.12 + 细噪声凹凸 + `jaw_shadow` 渐变（下颊压暗）+ 颊部腮红 mask；颈桩比头窄一圈、略后坐，让下颌在脖子上留一道阴影，头才「坐」在肩上。
- **静默片**：`speak()` 保留为 no-op 占位（不开口、不读台词），旧脚本不报错；表演全靠 `idle/look/blink/arm/move/walk` 与镜头。
- **验收**：3/4 侧与正侧面各抽一帧——侧脸能看出鼻梁、下颌、耳位才算过；正面只看眼睛会掩盖鼻梁和下巴的问题。
