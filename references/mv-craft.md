# MV 制作经验（pixel-story）

这份文档只记**可复用的做法**，不绑定任何一支具体片子。引擎层是通用的；故事、城市、角色名、字幕都写在内容层，换一支片就整段替换。

## 1. 三层分离：引擎 / 内容 / 配置

| 层 | 文件 | 谁改 | 规则 |
|---|---|---|---|
| 引擎 | `js/pixel-kit.js` `paint.js` `actors.js` `sets-*.js` `shot.js` `timeline.js` `variant.js` `grade.js` | 只在需要新场景/新镜头能力时改 | **不写任何一支片专属的城市名、台词、品牌字**；文字一律从 config 读 |
| 内容 | `js/film.js`（分镜）、`js/script.js`（字幕） | 每支片整段重写 | 示范故事只是格式样例，不是必选剧情 |
| 配置 | `js/config.js` | 建工程时写入，之后微调 | 片名/品牌/标语/`kicker`/`endTag`/分辨率/封面时间 |

判断标准：如果这段代码换一支片就不能用，它属于内容层，不属于引擎层。

## 2. 分镜数据（film.js）

- 一行 = 一拍：`{ t: 绝对秒数, shots: [...] }`；行内**等分**时长。
- 60s 片建议 **20–28 镜**，每镜 **2–3 秒**。少于 2 秒看不清，多于 3 秒会停。
- 每镜自动拿到唯一的 `v`（镜头序号）；场景库用它派生独立的配色、朝向、结构、天气与物件。**同一个场景可以重复出现，但不会出现同一张画面**。
- 最后一镜必须 `end: true`，并收在 `film.total = config.base` 上。
- 段落 `SECTIONS`：`verse` 平滑溶解、`chorus` 硬切、`bridge` 慢溶、`finale` 慢溶。切点语法只在这里定义。

常用镜头字段：

```js
{ s: 'street', m: 'pan-r', who: G(330, 214, 'walk') }        // 手绘场景 + 角色
{ g: 'crossing', m: 'pan-l', who: B(300, 232, 'walk', { umbrella: true }) }
{ s: 'insert', ins: 'key', m: 'in', cy: 160 }                // 桌面/物件特写
{ s: 'city', m: 'pan-r', card: true }                        // 片头卡
{ s: 'dawn', m: 'in', end: true }                            // 片尾卡
```

- 运镜 `m`：`hold` / `in` / `out` / `pan-l` / `pan-r` / `push-r` / `tilt-u` / `track`。
- 角色：`G(x, y, pose, opt)` / `B(x, y, pose, opt)`，pose = `stand|back|walk|run|sit`。
- 双人镜用 `duo`；行李 `case`；雨 `rain`；站台列车 `train`；特写 `ins`；工作装 `work`。
- `zoom` 是特写推近，上限 **2.6**；超过会糊掉像素格。
- `shard: false` 关闭该镜的碎片化变体（需要画面完全稳定时）。

## 3. 构图与相机

- 相机锚点：`cx/cy` 优先；否则用 `who` 或 `duo` 的位置；再否则用镜头自带 `x/y`。
- **双人镜必须让相机跟着主体**。只写 `duo` 不写锚点时，引擎会自动取 `duo`，不要手写一个和人物无关的 `cx`。
- `zoom` 会把画面推近，但**不会**把字幕牌移走；推近前先确认人物头部仍高于 y=222。
- 480×270 是逻辑画布，所有坐标按它写；输出 1080p 是 ×4、4K 是 ×8，像素不会被插值。

## 4. 角色与字幕安全区

- 底部字幕牌固定在 `y=232`、高 `26`，覆盖画布 **232–258**。人物脚底 `y ≤ 222`，行李 `y ≤ 234`，否则会被牌压住。
- 角色在暗底场景里要有对比：深色人物落在近黑背景上会看不见。抽帧时如果 45% 帧接近全黑，换场景或换站位，不要靠加亮整幅画解决。
- `variant.flip` 会整幅镜像；画面里如果有标牌文字，文字会反写。带文字的镜头要么关掉 flip，要么不要让文字进画。

## 5. 字幕（script.js）

- 每条 **6–18 个汉字**，**≤7 字/秒**，不重叠，第一条不要压在片头卡上。
- 字幕是独立图层，可以跨镜头切点；但不要跨拍讲完一整段，换拍就换句。
- 只写听得懂的口语，不写镜头说明、不写术语。
- 字幕牌用 12px 软边字（`K.plate` 内部已处理），笔画多的字也能读；画面里的标签与 HUD 仍是二值化硬边，别把长句塞进标签层。

## 6. 确定性（硬规则）

- 引擎只依赖 `local` 时间与 `shot.v`；禁止 `Math.random()` / `Date.now()`，随机走 `K.rnd(seed)`。
- 同一时刻两次渲染必须逐像素一致（`qa-mv` 会比对）。
- 画面裁切、抖动、粒子全部由帧时间驱动；暂停在任意时刻都应是一张完整构图。

## 7. QA 判据

`node tools/qa-mv.js .` 逐镜 45% 时刻检查：

- 画布 480×270、`imageSmoothingEnabled === false`；
- ≥8 种颜色、≥12% 非背景像素（防近黑/空白）；
- 同刻两次渲染最大差 ≤2 色阶；
- 镜头内 +0.45s 必须有变化（防静帧）；
- 每条字幕中点 `plate.alpha ≥ 0.5`；
- 最后 1.2s 片尾卡已完成。

`tools/qa-all.js` 再按每镜 30% / 78% / 切点前 0.25s 抽帧。**78% 是最容易出问题的一帧**：主体是否已经退干净、是否只剩残影、字幕是否压住主体。抽帧必须逐张看，不能只看报告。

## 8. 分辨率与音频

- 分辨率是交付规格，**建工程前必须问**：1080p（`renderScale: 1`）或 4K（`renderScale: 2`）。不要在没问的情况下默认 4K。
- 1080p 全片先审，4K 只在明确要求时渲；渲 4K 前先确认磁盘空间。
- 配乐可选：`npm run music` 生成 chiptune；不生成时 `encode.js` 自动输出无声 MP4。旁白可选，默认不用。
- 音乐只做底：有旁白约 0.40 并开侧链闪避；无旁白约 0.55。

## 9. 常见坏帧与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 整帧近黑 | 主体颜色与背景太接近 / 场景本身太暗 | 换场景或换站位；抽 45% 帧验证，不要只调亮度 |
| 人物被底牌切脚 | 人物 `y > 222` | 上移到 222；行李 234 |
| 只露出一个头 | 房间/室内镜头的坐标尺度与角色不匹配 | 这类镜头不要硬塞角色，用空镜 + 雨/灯做情绪 |
| 标牌文字反写 | `variant.flip` 整幅镜像 | 关 flip 或去掉画面文字 |
| 特写糊成色块 | `zoom > 2.6` | 降到 2.6 以内，或换更近的场景原型 |
| 同刻两次不一致 | 用了未播种随机/时钟 | 改 `K.rnd(seed)`，时间只从 `local` 来 |
| 镜头内没变化 | 纯 `hold` 且没有环境动画 | 加雨/雾/灯闪/人物呼吸，或换运镜 |
| 70% 后仍有半透明残影 | 元素退场没退干净 | 退场到 `opacity 0` 或被下一层完全遮挡 |

## 10. 加新场景 / 新原型

- 手绘场景：在 `js/sets-a.js`…`sets-e.js` 里注册 `S.<name> = { w, h, world(v, shot), live(g, t, shot, cam) }`；`world` 只画静态底，`live` 只画随时间变化的层。
- 程序化地点：在 `js/sets-gen.js` 的 `GEN` 里加原型，用 `qFor(shot)` 派生参数，保证不同 `v` 画出不同构图。
- 新场景必须进 `sceneKeys()` 能扫到的 `S.<name> = {` 形式，否则单测会判定引用不存在。

## 11. 交付前检查单

1. `npm test` 全绿（分镜连续性、2–3 秒、唯一 v、字幕、确定性、图层隔离）。
2. `npm run qa` 全绿，`qa/mv/` 抽帧逐张看过。
3. 封面帧能独立当缩略图（片名完整、无动画中间态）。
4. 1080p 审片通过后再按需渲 4K。
5. `encode.js` 输出后核对时长/分辨率/帧率/音轨；无声版是合法交付，不要为了“有声音”硬塞音乐。
